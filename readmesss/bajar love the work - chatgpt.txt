Para bajar las campañas de Love the Work (Cannes Lions, Spikes Asia, Dubai Lynx y Eurobest).

Hay que correr este script: 
love_the_work_descargador_2.py

( esta en la carpeta lovethework dentro de IDEAZITE )

de esta forma

python love_the_work_descargador_2.py --festival cannes-lions --year 2025
python love_the_work_descargador_2.py --festival eurobest --year 2025
python love_the_work_descargador_2.py --festival spikes-asia --year 2025
python love_the_work_descargador_2.py --festival dubai-lynx --year 2025

o 2026 o el año que sea

Si no se pone el festival, descarga todos los del año

python love_the_work_descargador_2.py --year 2025

--------

En la misma carpeta tiene que estar el archivo csv: track_catalog.csv
Ahi estan las categorías

Si detecto una categoría nueva o un cambio de nombre, hay que agregarla al final con este formato
festival,slug,nombre


Para Listar tracks sin scrapear: para saber que categorias lee y si hay alguna que no:

python love_the_work_descargador_2.py --festival eurobest --year 2025 --dry-run (no se si funciona eso)
